A real bug this demo surfaced

The WAF had never actually blocked anything on this edge.

The engine called ngx.re.compile() — which OpenResty doesn't have. Every regex rule threw attempt to call field 'compile', the fail-open wrapper swallowed it, and all traffic passed. It went unnoticed because no vhost had a policy bound until now. Fix: pass the pattern straight to ngx.re.find(v, pattern, "jois") — the o flag compiles once and caches per worker. Only waf_enabled vhosts are affected, so the blast radius is this demo.
